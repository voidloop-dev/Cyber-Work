1.4 Architectural principles
Follow these principles throughout development:

Every module must have a clearly defined responsibility.

Every module must produce standardized outputs.

Security events must be stored independently of AI-generated interpretations.

Sensitive operations must require appropriate authorization.

All important actions must be auditable.

Modules must continue functioning if an unrelated module fails.

External integrations must be replaceable.

Detection logic must be testable independently.

AI-generated conclusions must reference actual evidence.

The platform must identify when a collector or detection module stops working.
